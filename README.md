# Kindle Tagesanzeige

Uhr, Datum, Wetter (3 Tage) und ein Tagesspruch, optimiert für den Kindle 5 (D01100, 600 × 800 px, 167 ppi).

## Auf GitHub veröffentlichen (GitHub Pages)

1. Neues Repository auf github.com anlegen (z. B. `kindle-tag`), öffentlich.
2. `index.html` und diese `README.md` hochladen (Add file → Upload files).
3. Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
4. Nach ca. einer Minute erreichbar unter `https://<dein-name>.github.io/kindle-tag/`.
5. Diese Adresse im Kindle-Browser öffnen und als Lesezeichen speichern.

## Anpassen

Oben im Skript von `index.html`: `LAT`/`LON` (Ort), Aktualisierungsintervalle und die Liste `SPRUECHE`.
